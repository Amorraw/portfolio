S

Situation

Proprietary Smart TV app stores are closed ecosystems — they won't combine a personal recommendation engine with unified playback control across both touch and remote input.

T

Task

Design and prototype a self-hosted kiosk dashboard, running on a Raspberry Pi, navigable by both touch and a standard TV remote via HDMI-CEC.

A

Action

Chose Pi 5 + LibreELEC/Kodi + Node/Express + React (Chromium kiosk) + FastAPI/scikit-learn, wired the UI to Kodi's JSON-RPC API, and mapped CEC remote input to a five-column focus-driven grid.

R

Result

A documented, end-to-end reference architecture validated against real hardware limits (Pi 4 is too weak for 4K transcoding; LibreELEC needs a Chromium/WebView layer for a true kiosk UI) — not assumed to "just work."

Interview talking points

  • Hardware-aware software design — reasoning through CEC remote mapping and 4K transcoding limits before writing UI code.
  • Range beyond typical web-only portfolios: IoT protocols (Kodi JSON-RPC, HDMI-CEC), not just REST APIs.
  • The same "Node + Python recommender" split shows up here and in Cultura — a consistent, reusable architectural instinct.
