My_PersFin_App

GitHub Live site

A production Canadian personal-finance platform with its own ML microservice — built as the capstone for a UBC full-stack bootcamp, and still live today.

82-second live walkthrough recorded directly against persfin-app.onrender.com — dashboard → debt optimization → RRSP vs TFSA → ML forecast.
S

Situation

Mainstream budgeting tools are built for US financial products and ignore Canadian tax-advantaged accounts (TFSA/RRSP/FHSA/RESP) — and this project doubled as the required capstone for a UBC full-stack bootcamp.

T

Task

Design, build, secure, and deploy a production-grade, multi-service platform end to end — accounts, imports, budgeting, debt payoff, Canadian registered accounts, and an ML insights layer.

A

Action

Built a React/TypeScript frontend and Express/MongoDB API with session auth, a separate FastAPI ML microservice, CSV/PDF import, a debt-payoff engine, and a security hardening pass before launch.

R

Result

A live, two-service production deployment covering 10 realistic financial personas — satisfying the capstone requirement while functioning as a genuine consumer-grade product today.

Interview talking points

  • Why the ML layer is a separate FastAPI service instead of embedded in the Node API — independent deploy cadence and clean separation of concerns.
  • Walking through a real production incident: a Recharts v3 / Express 5 version mismatch broke the build, and how it was diagnosed and fixed.
  • Security hardening (rate limiting, at-rest token encryption for Plaid access) was an explicit final phase — and what I'd build in from day one next time.
  • Domain-specific product judgment: modeling Canadian tax-advantaged accounts instead of cloning a generic US budgeting tutorial.
